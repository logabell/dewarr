# Dewarr v0.3.5

This patch brings a redesigned Following page, more reliable downloads and imports, simpler library setup, and explicit linking for existing OIDC accounts.

## Following and book pages

- Browse followed authors and series with catalog totals, books in your library, upcoming releases, and latest books. Search, filter, sort, and expand their book lists, or browse releases grouped by month.
- Follow an author directly from their page or a book's details. Co-authored books offer individual author controls. Following remains separate from download-policy approval.
- Refresh release shelves and expanded books when catalog updates complete, including follows hidden by filters or pagination. Shared books use the newest eligible saved publication date before being classified as upcoming or recently published.
- Place Follow author beside Add to reading list. Long titles and subtitles remain fully visible without a Show full title toggle.

## Downloads and import review

- Resolve validated Prowlarr HTTP(S) download redirects for NZB and torrent files, preserving artifact inspection, credential isolation, and network validation. Sources now explain when no eligible torrent indexers are available. This addresses the confirmed acquisition failure in [#32](https://github.com/logabell/dewarr/issues/32) and improves diagnostics for [#34](https://github.com/logabell/dewarr/issues/34).
- Recognize parenthesized release formats and catalog subtitles, allow eligible automatic NZB dispatch, and reconcile completed SABnzbd/NZBGet jobs across queue and history. Import inspected Usenet output without applying a torrent-manifest comparison to NZB archive names.
- Explain uncertain download states and simplify book matching and import review, reusing the selected book's metadata and keeping ebook/audiobook actions consistent.
- Fix Deluge 2.x connection testing by using its supported version RPC ([#35](https://github.com/logabell/dewarr/issues/35)).
- Improve AudiobookBay searches that redirect capitalized queries to the homepage, match corroborated series/volume postings, and import completed releases with matching title and author evidence ([#39](https://github.com/logabell/dewarr/issues/39), [#40](https://github.com/logabell/dewarr/issues/40), [#41](https://github.com/logabell/dewarr/issues/41)). Wrong-volume and ambiguous files continue to require review.

## Library setup and native workflows

- Preserve library access during display-only connection edits and provide sync/recovery controls when saved audiobook folders disappear ([#36](https://github.com/logabell/dewarr/issues/36)).
- Retire unreferenced legacy download mappings and secure newly created or empty Dewarr-owned legacy staging directories despite inherited permissions, addressing the NAS follow-ups in [#29](https://github.com/logabell/dewarr/issues/29). Existing files, operator-managed folders, and mappings still needed by inspected work are preserved.
- Remove the remote marker challenge that could reject valid mounts because of backend permissions or filesystem caches ([#45](https://github.com/logabell/dewarr/issues/45)). Setup checks local access and backend configuration; actual book detection still determines whether an import completes.
- Add native Audiobookshelf/Grimmory workflow checks, recover direct Grimmory metadata publication after interrupted responses, and support an administrator-owned single-EPUB Bookdrop review handoff. Bookdrop delivery stays pending until the actual imported library copy is linked; it does not automatically approve Grimmory review.

## Account sign-in

- Link an existing local account, including the first administrator, to OIDC after verifying the local password and authenticating with the provider. Unlinking retains local password access.
- Administrators can rename accounts, change display names, and disable accounts while retaining history. Disabling revokes sessions and protects the current and last active administrator. These changes address the username/OIDC setup path reported in [#37](https://github.com/logabell/dewarr/issues/37). Account removal and administrator-managed Plex unlinking are not included.

## Upgrade

Pull `ghcr.io/logabell/dewarr:v0.3.5` or `ghcr.io/logabell/dewarr:latest`, then recreate Dewarr. Stable images support `linux/amd64` and `linux/arm64`.

Back up PostgreSQL and the config directory first: this release includes native-import and OIDC-linking database migrations, applied at startup. For a previously failed library route, run **Save & verify folder** again. Existing successful route receipts remain usable while their configuration is current. Incorrect mount mappings can pass local setup checks but will remain unconfirmed when the backend cannot detect the actual book.

The limited search-result reports in #32/#34, the Soulseek follow-up in #31, and the reverse-proxy report in #27 still need installation-specific confirmation. This release does not claim those reports are completely resolved.
