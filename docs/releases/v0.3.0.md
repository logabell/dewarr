# Dewarr v0.3.0

Dewarr 0.3.0 adds notifications, author and series follows, request quotas, more torrent clients, and automatic recovery for failed downloads. It also improves connection setup and fixes the mounted-library and SABnzbd problems reported in 0.2.3.

## New features

- **Notifications:** Discord, ntfy, JSON webhooks, and administrator-managed Apprise channels, with event preferences, discovery digests, and delivery history.
- **Author and series follows:** monitor future books, review back-catalog selections, apply filters and exclusions, and wait until release day before acquiring upcoming books.
- **Transmission and Deluge:** connect these torrent clients, map their download folders, and use them in download routes. Client capabilities are shown explicitly; seeding-copy rename remains qBittorrent-only.
- **Request quotas:** rolling book and size limits, pending-approval caps, installation/role/user policies, remaining-quota displays, and automatic requests that wait for capacity.
- **Failed-download recovery:** detect stalled or failed transfers, blocklist rejected releases, and try eligible replacements within the original request constraints and attempt limit. Requests show their attempt history, and users can report bad content.

## Fixes and setup improvements

- Fix SABnzbd 5 connection tests, authenticate through POST form fields, resolve relative completion folders, and validate category settings. Track sanitized attempt names and look up completed history entries by job ID ([#8](https://github.com/logabell/dewarr/issues/8), [#16](https://github.com/logabell/dewarr/pull/16)).
- Fix mounted-library probes when directory identities change after a rename. Settle SMB writer timestamps before recording the source identity, and allow bounded backend folder-visibility delays ([#12](https://github.com/logabell/dewarr/issues/12), [#13](https://github.com/logabell/dewarr/pull/13), [#14](https://github.com/logabell/dewarr/pull/14)).
- Fix setup probes on mounts whose open directory handles retain the old path after rename. Preserve copy fallback when hardlinks are unavailable, and report the failing operation and original filesystem error ([#15](https://github.com/logabell/dewarr/issues/15)).
- Improve Soulseek/slskd download-folder detection and mapping. Browse mounted folders directly and see clearer connection and folder status throughout settings ([#17](https://github.com/logabell/dewarr/issues/17)).
- Accept same-origin requests through the browser's direct address as well as the configured public URL, while retaining origin validation ([#20](https://github.com/logabell/dewarr/issues/20)).
- Add configurable direct fallback when a MyAnonamouse proxy fails. Review this setting if your installation requires all MAM traffic to use a proxy.
- Harden personal notification destinations against DNS changes and restrict Apprise's plugin transports to administrators.

## Upgrade

Back up PostgreSQL and the configuration directory containing the encryption key. This release adds database migrations, which the container runs before starting the application.

Pull `ghcr.io/logabell/dewarr:v0.3.0` or `ghcr.io/logabell/dewarr:latest`, then recreate the Dewarr container. Images support `linux/amd64` and `linux/arm64`.

```sh
docker compose pull
docker compose up -d
```
