# Dewarr v0.3.4

This patch improves shared ebook/audiobook libraries, mounted-folder setup, and import recovery. It follows up on [#29 / NOR-66](https://github.com/logabell/dewarr/issues/29).

## Library folders

- Point ebooks and audiobooks at the same mounted library folder. Setup offers “Use the same folder” and labels both formats as shared.
- Folder names are unrestricted. Dewarr follows the selected paths and mount boundaries, including library folders mounted directly beneath `/` and different paths reported by Audiobookshelf.
- Shared destinations reuse their staging route. Invalid saved automatic staging choices are reselected; existing recovery journal locations are preserved.
- Overlap errors now identify and log the conflicting paths and configuration keys, including previously configured download roots.
- Read-only downloads remain supported through verified copy routes, with source files preserved.

## Import stability and setup clarity

- New imports into shared roots use separate folders labeled Ebook or Audiobook. Naming previews, manual imports, automatic imports, and audiobook part combining use the actual destination. Unrelated libraries and pending plans keep their existing names.
- Manual review retains the selected destination through publication and can refresh stale destination settings after a configuration change.
- Shared-folder badges, expandable staging details, and the folder shortcut follow the existing dark design and responsive layout, including long paths on mobile and keyboard access.

Existing book folders are not renamed or merged. Automatically appending a second format to an existing book folder is not included.

## NOR-66 diagnostic note

The reported `/library` and `/downloads` paths pass validation in the equivalent tested setup. The exact 422 on the reporter's NAS remains unconfirmed without its effective configuration. If it persists after upgrading, the new error and warning log show which paths conflict; include that message in #29 rather than moving the existing library or guessing at folder names.

## Upgrade

No new database migration is included. Pull `ghcr.io/logabell/dewarr:v0.3.4` or `ghcr.io/logabell/dewarr:latest`, then recreate the Dewarr container. Stable images support `linux/amd64` and `linux/arm64`.
