# Dewarr v0.3.7

This patch improves series discovery, collection downloads, automatic source matching, and request progress and cover display.

## Series and collections

- Show a cleaner Hardcover reading order with English main-book representatives, while keeping supplements and other catalog entries available separately.
- Improve series metadata loading and separate list-building from series requests.
- Detect collection contents from MAM descriptions, series ranges, release details, and torrent file and folder names. Match the included books to Hardcover without assuming a pack contains an author's entire bibliography.
- Present matched collection books with covers and select supported matches by default. Allow individual book/file selection and catalog-match corrections before downloading.
- Share verified collection transfers across selected books and validate individual book and recording identities during import.

## Automatic requests and downloads

- Select missing ebooks and audiobooks using personal format defaults, and recalculate missing-format counts when the requested format changes.
- Default series requests to automatic acquisition with a simpler request panel and clearer progress.
- Preserve catalog metadata through collection requests and reconcile selected downloads automatically.
- Retry an unsuccessful automatic search immediately with an author-qualified query before applying the normal backoff. Existing eligible waiting series requests receive this recovery once after upgrade.
- Open source searches in the requested ebook or audiobook format and retry temporary cover-image failures.

## Upgrade

Pull `ghcr.io/logabell/dewarr:v0.3.7` or `ghcr.io/logabell/dewarr:latest`, then recreate Dewarr. Stable images support `linux/amd64` and `linux/arm64`.

This patch adds no database migrations. Ambiguous collection contents and conflicting identities still require review; confirmed collection selections remain tied to their approved torrent.
